# CodeAlpha Financial Health Dashboard 📊

An interactive **Financial Health Dashboard** built in **Power BI**, developed as part of my **Power BI Internship with [CodeAlpha](https://www.codealpha.tech)**.

## 🎯 Objective
Analyze an organization's financial performance with real-time insights — tracking sales, profitability trends, and cost structure to support data-driven business decisions.

## 📌 Key Features
- **KPI Cards**: Total Sales, Total Profit, Profit Margin %, Total COGS, and Year-over-Year Sales Growth %
- **Trend Analysis**: Line chart tracking Sales and Profit over time
- **Segment Breakdown**: Bar chart comparing performance across customer segments (Government, Enterprise, Midmarket, etc.)
- **Geographic Insights**: Map visualization of sales distribution by country
- **Interactive Filtering**: Month-wise slicer for drilling into specific periods

## 🛠️ Tools & Techniques
- **Power Query** – Data import and preparation
- **DAX (Data Analysis Expressions)** – Custom measures including time-intelligence calculations (YoY Growth using `SAMEPERIODLASTYEAR`)
- **Data Modeling** – Built a dedicated Date table with an active relationship to the Financials table
- **Power BI Desktop** – Report design, visuals, and formatting
